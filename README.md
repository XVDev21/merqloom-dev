# Merqloom

Merqloom is an independent commerce demonstration. The foundation includes a Next.js Studio entry, a server-rendered catalog and Medusa Admin. Fictional desk accessories use a PHP demo region. The direct-order and mock supplier journeys are scheduled for M1 and M2.

[Run locally](docs/architecture/LOCAL_ENVIRONMENT.md) · [Architecture](docs/architecture/SYSTEM.md) · [Milestones](docs/roadmap/TASKS.md) · [Evidence](docs/verification/BASELINE.md) · [Sol handoff](docs/handoffs/SOL_M1_MASTER_PROMPT.md)

The backend and frontend packages derive from the official MIT-licensed Medusa DTC starter. The repository includes its license. The baseline uses system fonts and project-authored pages without third-party product imagery.
