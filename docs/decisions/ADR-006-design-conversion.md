# ADR-006: Design and claim governance

Status: policy approved; visual direction provisional until actual screenshots pass review.

Keep Ink/Ivory/Teal/Gold roles subject to measured contrast. Preserve the complete original Studio copy as a draft, not production claims. Shorten visual headings where needed while preserving the narrative in supporting copy. The draft eyebrow is omitted under the taste rules; the tagline can appear in ordinary text. Do not shrink the full long hero into unreadable mobile type.

Project precedence: truthful functioning controls, accessibility and restrained purposeful motion take priority over decorative animation quotas. Taste defines composition and critique; motion defines behavior and reduced-motion policy. Document any inspector exception by rule and rationale; never claim zero failures if exceptions remain unresolved.

The working Store demo is the primary public action. A request-preview action requires an authorized destination. Keep the engineering roadmap in the repository and disclose fictional products, payments and shipping where they shape the visitor's decision. Publish only verified capability claims. See the [public experience brief](../design/PUBLIC_EXPERIENCE.md) for the public content policy and review criteria.
